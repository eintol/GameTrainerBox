# GameTrainerBox 修改器功能说明（活文档）

> 本文档面向使用者与后续维护者，描述 GameTrainerBox 的功能、使用方式与数据流。**功能变更/新增时必须同步更新
> 对应章节与"最后更新"日期**；深度实现细节不在本文（见「辅助工具使用说明」「踩坑记录」）。
> 最后更新：2026-09-05

## 功能总览

| 模块 | 功能 | 状态 |
|---|---|---|
| 首页 | 已适配游戏列表、运行状态、进入修改页 | 可用 |
| 属性修改 | 五维属性实时查看 / 修改 / 锁定 / 上限拉满 | 可用 |
| 容器扩容 | 每容器独立设置格子数，游戏内热生效 | 可用 |
| 日志 | 主进程操作日志实时推送 | 可用 |

当前适配游戏：**生存日志（Survival Log）** 1.0.15704（Unity 6000.2.0a1, IL2CPP）。

## 首页

- 游戏卡片列出全部已适配游戏，实时显示目标进程是否在运行
- 点击卡片进入对应训练页；左上"返回"回到首页（首页才显示 GameTrainerBox 顶栏）

## 训练页

进入训练页会**自动附加游戏进程并扫描属性字典**。扫描要求：游戏已启动且**已进入存档（局内）**——
主界面时 Attr 类未初始化，无法扫描（这是游戏机制，不是故障）。

### 属性修改

- **实时查看**：生命 / 饱食度 / 士气 / 体力 / 健康* 五项，含当前值与上限
  （健康* 是内部隐藏属性，界面上没有对应条目，一般不用改）
- **修改**：在"改为"列填显示值 → 点该行"应用"。显示值 = 内存值 ÷ 1000
- **锁定**：打开开关后每 0.3 秒自动把属性写回目标值（高频写回，不是冻结）
- **上限→500**：一键把该属性上限设到游戏硬封顶 500（自动处理硬封顶字段）

扫描机制：全堆签名扫描 + 遍历双路径定位属性字典（首次约 2~4 秒），同局内重扫走缓存（0.2 秒）。
堆里存在 模板/镜像/邻居实体 等多个同形字典，引擎自动鉴别出主角的真字典
（模板过滤 → 3 秒动态采样 → 上限总分排序），鉴别过程日志可见。

### 容器扩容

配合游戏侧 BepInEx 插件（见「容器扩容Mod说明」），为**每个容器独立设置目标格子数**：

- **启用**开关：切换后立即写入配置
- **浏览并添加容器...**：弹出全部容器表格——中文名称、原始格子、当前格子；
  默认「只看正在使用」（局内活容器），支持名称/ID 筛选；每行「添加」加入工作区，
  也可「添加全部正在使用」
- **工作区表格**（卡片内直接编辑）：每行 新列 / 新行（下限自动锁定为原始尺寸）、还原、移除
- **应用**：写入后游戏运行中约 **3 秒内热生效**，无需重启游戏
- **记忆**：工作区自动保存在本机（localStorage），重开修改器不丢；点过"应用"的配置
  持久化在插件配置文件里，随游戏存档正常读写

要点：**只扩不缩**——缩小会让已放入新区域的物品读档越界（触发游戏反作弊）。
缩小某容器的流程：清空该项 → 重启游戏（还原原始大小）→ 再设置更大的值。

### 日志

训练页底部固定高度日志区，实时显示附加/扫描/写入/容器配置等主进程日志，内部滚动。

## 数据与配置文件位置

| 文件 | 归属 | 说明 |
|---|---|---|
| `userData/attr_cache.json` | GameTrainerBox | 属性字典扫描缓存（同局加速；跨局自动失效） |
| `BepInEx/config/...containerexpand.cfg` | 插件 | 容器扩容总开关 EnableResize |
| `BepInEx/config/...containerexpand.overrides.txt` | 插件 | 每容器目标格子（`id:列:行` 逗号分隔） |
| `BepInEx/config/...containerexpand.containers.json` | 插件 | 容器清单（中文名/格子/是否正在使用），进局内后完整 |
| 浏览器 localStorage `gb:container-workbench:<游戏id>` | GameTrainerBox | 容器工作区记忆（含未应用的草稿） |

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| 扫描报"Attr 类尚未初始化" | 没进存档（进局内再扫）；或游戏刚更新（走重定位流程，见踩坑记录 C1） |
| 扫描报"签名扫描+遍历均失败" | 游戏更新后 RVA 失效，跑 `scripts/locate-attr-class.ts` 重新定位 |
| 属性数值和游戏对不上 | 旧版本挑错字典（已修复）；确认 GameTrainerBox 为最新构建并重扫 |
| 容器改了不热生效 | 确认游戏内插件 ≥v0.8、GameTrainerBox 为最新构建；看 BepInEx 日志 `overrides loaded` |
| 容器清单不全 | 进局内后才完整；或点对话框内"刷新" |
| 修改后游戏内数值没变 | 属性写入在游戏回合/数值变动时刷新属正常；锁定可强制 |
